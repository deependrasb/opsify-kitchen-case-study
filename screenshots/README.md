## Redaction applied

Before adding these files, screenshots were processed to remove or cover:

- Private / staging hostnames in the browser chrome (cropped out)
- Vendor and outlet contact details (addresses, phones, emails)
- Third-party brand / placeholder restaurant names in guest copy
- Personal account names on guest order history
- Concrete order identifiers
- Embedded map pins and real map locations

## Capture guidelines (for future shots)

1. Use fake restaurant, menu, and staff names only.
2. Crop the browser address bar (never publish private hosts).
3. Do not include DevTools, config pages with API keys, or payment-secret screens.
4. Prefer PNG/WebP at readable desktop width.

If a new capture might identify a client, discard it. This folder is destined for a **public** GitHub repository.
